# Temporal-Regime Design for Programmable Tibial Mechanostimulation

Working PHY 600-style white-paper workspace.

## Primary question

Can the temporal organization of controlled tibial mechanical loading be treated as an independent experimental variable for probing osteocyte mechanotransduction and downstream bone-brain signaling?

The project begins from Cai et al., *Tibial bone compression promotes recovery after brain injury through osteocyte PIEZO1*, Nature Neuroscience (2026):
https://www.nature.com/articles/s41593-026-02422-w

The first research phase is literature synthesis and benchtop instrumentation design. It does not define a human stimulation dose and does not treat animal force values as transferable to humans.

## Workflow

Round 1 follows the earlier neuro white-paper workflow in this repository.

1. Run the five section-specific Emergent Mind search families.
2. Save each raw research summary beside its section search manifest.
3. Stop after Round 1.
4. Return the pasteback block defined in `GROKBOT_RUNBOOK.md`.
5. Review the evidence before creating claim families, outcome families, refuting-result searches, or validation searches.
6. Expand only from claims that appear in the first synthesis.

The later search tree is expected to grow into folders analogous to the earlier neuro project:

- `claims_*`
- `outcome_*`
- `outcome_refutingResult`
- `outcome_validations`

Those folders are intentionally not created yet.
